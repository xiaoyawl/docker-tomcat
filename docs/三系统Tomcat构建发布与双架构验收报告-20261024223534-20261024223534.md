# 三系统 Tomcat 构建、发布与双架构验收报告

创建及修改：20261024223534（北京时间）；维护者：Manta <manta.ops.dstw@gmail.com>。

## 结果与边界

- 本次补齐 CentOS Stream 9、Rocky Linux 9 共 26 个组合，远程 Buildx 构建及 52 个平台运行结果通过。
- 13 个 Alpine 组合复用已发布产物，没有重新构建；三系统合计 39 组合、78 个已验收平台运行结果。
- 新增发布 104 个版本标签，按 Tomcat 8.5 → 9.0 → 10.1 → 11.0、同线 JDK 低到高串行执行，各组合逐一核对后继续；最后重申 latest 至原 Alpine 默认产物，digest 保持不变。
- 最终全量核对 157 个标签（156 版本标签 + latest）、314 个平台引用；远端共 278 个标签，本次范围外 173 个历史标签 digest 未变。
- 10 个新增 JDK/系统基础环境共 20 个平台的实际用户态抽查通过：CentOS Stream 9 / Rocky Linux 9，glibc 2.34。
- amd64 原生；arm64 为 QEMU 模拟。版本、实际 JVM 架构、Oracle CheckCerts、时区、SHA-256、正常 HTTPS、最小 JSP 均通过。未进行 ARM 真机、真实业务 WAR、自定义 truststore 及生产部署。
- Tomcat 8.5.100 已停止上游维护，仅作历史兼容；更新 JDK 不修复 Tomcat 自身后续漏洞。

- JDK 完整版本：8u511-b32、11.0.33.0.2、17.0.21.0.2、21.0.13.0.2、25.0.5.0.2。
- 两个新增系统采用 `benyoo/jdk:<完整版本>-<centos9-stream或rockylinux9>-20261024`；10 个公开基镜像均核对双架构。
- 复用构建节点已保存的 JDK OCI，每份 index 与公开标签一致、全部 blob 哈希验证通过；没有换用其他版本。原始 JDK 产物未改动。

- 每个新批次运行 `make prepare` 发现维护分支最新正式补丁版后冻结矩阵；8.5 固定。本次重新解析仍为 9.0.123 / 10.1.61 / 11.0.27。
